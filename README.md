# Crypto Portfolio Manager

## Overview
This is a Python-based console application that helps users manage a simple
cryptocurrency portfolio. The program allows users to add crypto assets,
view their portfolio summary, and save the portfolio details to a text file.

This project was created to practice Python fundamentals such as functions,
lists, dictionaries, loops, and file handling.

## Features
- Add cryptocurrencies with amount and price in USD
- View a formatted portfolio summary
- Calculate total portfolio value
- Save portfolio data to a text file
  


## Notes
This project uses manual price input and does not connect to live crypto data.
It is intended for learning and demonstration purposes.
